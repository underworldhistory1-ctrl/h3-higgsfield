# ترقية H3 Studio إلى V2 — 3 أكتوبر 2026

V2 أصبحت الواجهة الأساسية في هذا الريبو. الترقية مبنية على نسخة V2 التي اختبرها المستخدم على سيرفره، مع مراجعة الكود واختبارات الخدمات والجراف والمتصفح. لا يوجد ضمان عام لكل توليفة برومبت أو LoRA؛ المعاينة والاستماع إلى ناتج كل تجربة هما حكم الجودة.

## التثبيت أو التحديث

استخدم install.sh على السيرفر Linux من نسخة مصدر منفصلة، أو install.ps1 للتثبيت Windows لمن يحتاجه. ينسخان جميع وحدات V2 والواجهة، ويثبتان محرك التكملة المثبت على revision 361624fb406b63eb6694442eac6c895fc1533a70 في ريبو مستقل. لا يوجد تنزيل موديلات أو تشغيل GPU على جهاز التطوير بسبب نشر هذه الترقية.

لا تثبت h3_studio وh3_studio_v2 في نفس عملية ComfyUI: هما يسجلان نفس النودز والمسارات. المُثبّت يرفض وجود نسخة V2 أخرى في نفس custom_nodes بدل إنشاء تعارض. النسخة المثبتة بالطريقة الأساسية تُفتح عبر /extensions/h3_studio/index.html وتحمل علامة V2؛ النسخة الجانبية الحالية على سيرفر المستخدم تبقى عبر /extensions/h3_studio_v2/index.html.

تحديث الريبو الأساسي لا ينقل أو يحذف مشاريع النسخة الجانبية، ولا يغيّر خدمات السيرفر الحالية. احتفظ بمجلد V2 الحالي ومسارات input/output/lab_storage/h3_lab_contexts كما هي. عند الانتقال لسيرفر آخر صدّر مشروع ZIP من الواجهة واستورده؛ لا تنقل سياقات أو ملفات بين عمليات مختلفة يدويًا دون حفظ المصدر.

المُثبّت يحفظ نسخ الملفات التي يستبدلها تحت .h3-backup، ولا يحذف المخرجات أو الأوزان. فحص ما بعد التشغيل يراجع ملفات الواجهة وجاهزية التوليد والكي فريمز والتكملة، ولا يكتفي بوجود عملية سيرفر.

## الاستخدام الصحيح

- الخطوات العادية 8–100، والافتراضي 20؛ Turbo يبقى 4–8 ومخصصًا لـFL2VA.
- References تستخدم Ref2VA؛ دور Storyboard يرسل ورقة اللوحات كتوجيه، دون تقسيم أو توقيت آلي.
- Frames تستخدم FL2VA؛ البداية/النهاية صورتان، والكي فريمز صور منفردة بتوقيت، دون مينشن خاص بها.
- مصدر Extend منفصل عن فيديو المرجع. تبديل checkpoint لسياق محفوظ يتطلب المسار الصريح لإعادة ترميز الفيديو.
- إعدادات LoRA وملاءمة الصور محفوظة في المشاريع ولا تُعاد كتابتها عند تحديث الاتصال.

## أدلة المراجعة

نجح 98 اختبار Python و29 اختبار JavaScript، وتجارب متصفح الفيديو والصور والتكملة، وفحص تثبيت ونسخ احتياطي فعلي على مجلدات مؤقتة دون موديلات. حزمة ZIP تتضمن جميع ملفات V2 وبنهايات أسطر Linux للسكربتات. الفاحص المعدّل اجتاز السيرفر الحالي على Python 3.10.18 وأظهر جاهزية التوليد والتكملة والكي فريمز، ووجود فيديوهين في مكتبة V2. المستخدم أفاد بنجاح عدة تجارب؛ ذلك لا يستبدل تقييم جودة كل إعداد أو وصلات Extend غير المختبرة.
